Safety / deployment

How this workstation is intended to be used

Receive-only application: the serial capture engine never sends Modbus frames.

Use a separate high-impedance / isolated USB-RS485 adapter in parallel with the live A/B pair for true passive monitoring.

The web server binds to 127.0.0.1 by default. Only use 0.0.0.0 on a trusted engineering network.
